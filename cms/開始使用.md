# 🎯 Strapi CMS - 開始使用

歡迎使用 NOEINOI Portfolio 的 Strapi CMS 系統！

## 📖 我應該從哪裡開始？

根據您的目標，選擇適合的指南：

### 🚀 我想要快速開始

**目標：** 儘快看到結果，不需要了解細節

**時間：** 15-20 分鐘

**步驟：**
```bash
cd cms
npm install
```

然後參考：[`docs/quick-start.md`](./docs/quick-start.md)

---

### 📚 我想要深入學習

**目標：** 了解 Strapi 的運作方式和架構

**時間：** 30-45 分鐘

**步驟：**
1. 先閱讀 [`INSTALLATION.md`](./INSTALLATION.md) 了解整體架構
2. 再參考 [`docs/strapi-setup.md`](./docs/strapi-setup.md) 詳細設置

---

### 🔄 我想要匯入資料

**前提：** 已完成 Strapi 安裝和 Content Types 設置

**時間：** 5-10 分鐘

**步驟：**
參考：[`docs/data-import-guide.md`](./docs/data-import-guide.md)

---

## 📋 完整安裝流程（推薦順序）

如果這是您第一次使用，建議按照以下順序：

1. **📖 閱讀概覽**
   - 先看 [`README.md`](./README.md) 了解專案架構
   - 再看 [`INSTALLATION.md`](./INSTALLATION.md) 選擇安裝方式

2. **🔧 安裝 Strapi**
   - 跟著 [`docs/quick-start.md`](./docs/quick-start.md) 完成安裝
   - 或選擇 [`docs/strapi-setup.md`](./docs/strapi-setup.md) 深入學習

3. **📦 建立 Content Types**
   - 參考 [`docs/strapi-setup.md`](./docs/strapi-setup.md) 建立所有必要的類型

4. **📥 匯入資料**
   - 使用 [`docs/data-import-guide.md`](./docs/data-import-guide.md) 匯入現有資料

5. **🎨 連接前端**
   - 設置 portfolio 專案的環境變數
   - 測試資料是否正確顯示

## ⚡ 快速命令參考

```bash
# 安裝依賴
npm install

# 開發模式啟動（有熱重載）
npm run develop

# 生產模式啟動
npm run start

# 建置生產版本
npm run build

# 匯入資料
npm run import-data
```

## 🎯 設置檢查清單

完成安裝後，請確認：

- [ ] Strapi 已安裝並可以啟動
- [ ] 已建立管理員帳號
- [ ] 所有 Content Types 都已建立
  - [ ] feed.heading Component
  - [ ] feed.paragraph Component
  - [ ] feed.image Component
  - [ ] feed.video Component
  - [ ] feed.list Component
  - [ ] project.paragraph Component
  - [ ] project.quote Component
  - [ ] project.blockquote Component
  - [ ] project.image Component
  - [ ] project.section Component
  - [ ] project.info Component
  - [ ] feed-item Collection Type
- [ ] API 權限已設置（Public role）
- [ ] API Token 已建立並加入 .env
- [ ] 資料已成功匯入
- [ ] 可以在管理面板看到資料
- [ ] API 端點可以正常訪問
- [ ] 前端專案已連接並可以讀取資料

## 💡 實用連結

### Strapi 管理面板
- 登入：http://localhost:1337/admin
- Content Manager：http://localhost:1337/admin/content-manager
- Media Library：http://localhost:1337/admin/plugins/upload
- Settings：http://localhost:1337/admin/settings

### API 端點
- Feed Items：http://localhost:1337/api/feed-items
- 詳細資料：http://localhost:1337/api/feed-items?populate=deep
- 單一項目：http://localhost:1337/api/feed-items/[id]?populate=deep

### 外部資源
- [Strapi 官方文件](https://docs.strapi.io/)
- [Strapi Discord 社群](https://discord.strapi.io/)

## 🎉 完成後...

成功設置後，您可以：

1. **📝 管理內容**
   - 在 Strapi 管理面板中編輯專案
   - 新增、修改、刪除內容
   - 上傳和管理圖片

2. **🎨 自訂前端**
   - 修改 portfolio 專案以顯示不同的資料
   - 調整版面和樣式
   - 新增更多功能

3. **🚀 部署上線**
   - 將 Strapi 部署到雲端（Heroku, Railway, DigitalOcean）
   - 設置 PostgreSQL 或 MySQL 資料庫
   - 配置 CDN 來優化圖片載入

4. **📊 進階功能**
   - 設置多語言支援
   - 建立自訂 API 端點
   - 整合第三方服務
